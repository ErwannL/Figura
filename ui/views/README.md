# ui/views/

UI screens.

## How it works

`runs.ts` list, `new-run.ts` form, `run.ts` detail (verbatim refusal, lifecycle, report downloads, calibration upload, persona inspector with screenshots, facts, friction, rule), `compare.ts` A/B, `personas.ts` catalogue, `explore.ts` explorer runs (form fields, live progress, anomalies with filters and replay, side-by-side gallery, JSON export).
